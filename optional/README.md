# optional/ —— 可选的飞书集成

> **这个目录整篇都可以不读。** 不装 `lark-cli` 的工作区，招聘主流程
> （init → grill → daily 寻源/初筛/台账 → 本地简历 review → 驾驶舱）完全不受影响：
> 日报落本地 Markdown、约面试输出手动建会清单、简历直接丢本地文件。
>
> 主线 skill 文档只保留一行指针指到这里，具体流程都在本目录。
> 只有你明确要做「发飞书文档 / 推 IM 卡片 / 从飞书邮箱收简历 / 自动建日历日程」时才需要读。

## 文件

| 文件 | 内容 | 触发条件 |
|---|---|---|
| `lark-integration.md` | 飞书邮箱收取 BOSS 简历（发件域白名单、附件风险筛、SHA-256 去重）、飞书云文档日报、飞书日历面试预约的完整命令流程 | 用户明确要求对应动作 |
| `lark-daily-card.md` | 飞书互动日报卡片：五层结构、Card JSON 2.0 字段坑、美观度自查、发送命令 | 用户说「日报也发我卡片」「推到群里」「发飞书」 |

## 设计说明

把这些内容从主线摘出来，是为了**降低 agent 的上下文成本**：飞书路径在主线上不产生任何动作，
但每次读主线文档都会进上下文。摘出去之后：

- 不用飞书 → agent 永远不读这个目录，主线更聚焦
- 用飞书 → 指针清楚，该读的时候读得到，内容一字未少

所有飞书路径都保留在 `optional/`，没有删任何能力。
